# OfferPSP Control Bridge

Новый staff frontend OfferPSP: единый капитанский мостик для мерчей, PSP,
офферов, matching, сделок и субагентов.

## Что уже подключено

- командный центр с очередью внимания и живой воронкой;
- входящие заявки, реестр мерчей и Kanban pipeline;
- карточка мерча с matching, ручным shortlist, client-safe preview и отправкой;
- Deal Desk: PSP review → Telegram → Zoom → won/lost;
- закрытый реестр PSP, контакты, версии маржи и актуальность условий;
- редактор нормализованных офферов, ставок, лимитов и settlement;
- реестр субагентов, закрепление merchant organizations и агентская маржа;
- аналитика воронки и состояния supply;
- глобальный поиск по мерчам, PSP и маршрутам;
- feature flags для модулей, которые ещё не подключены к бизнес-логике.

Бизнес-операции используют существующие staff-only Supabase RPC. Настоящий PSP,
его базовая ставка и внутренние слои маржи не выводятся клиенту.

## Локальный запуск

1. Скопировать `.env.example` в `.env.local`.
2. Установить зависимости: `npm install`.
3. Запустить: `npm run dev`.
4. Проверить: `npm run build` и `npm run lint`.

`.env.local`, `dist` и `node_modules` исключены из Git.

## Установка как приложение

Captain's Bridge можно установить из Brave, Chrome или Edge через значок установки
в адресной строке. Приложение откроется в отдельном окне и останется связано с
актуальной web-версией. Приватные экраны и операционные данные намеренно не
кэшируются для офлайн-работы.

## Основа интерфейса

Frontend основан на бесплатном TailAdmin React и сохраняет его MIT-лицензию в
`LICENSE.md`. Готовые UI-компоненты используются как каркас; логика OfferPSP,
RPC-контракты, конфиденциальность supply и рабочие процессы являются нашей
реализацией.
